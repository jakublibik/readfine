API Documentation

Use your token to access the REST API from scripts, clients, or external tools. Machine-readable spec: /openapi.json (import into Postman, Insomnia, etc.)

Authentication

Add the token to every request as a Bearer header:

Authorization: Bearer <your-token>

For scripts and long-running integrations, use an API token created above — it does not expire and can be revoked here at any time. The short-lived JWT from POST /auth/token (valid 60 minutes) is meant for interactive logins and is invalidated when you change your password.

Base URL

{{ request.base_url }}api/v1

Example

curl -H "Authorization: Bearer <token>" \
     {{ request.base_url }}api/v1/articles?unread_only=true

Endpoints

Method Path Description
Articles
GET /articles List articles. Params: feed_id folder_id unread_only starred_only archived_only q limit offset
GET /articles/{id} Get article detail (includes readable content)
PATCH /articles/{id} Update state. Body: {"is_read": true} {"is_starred": true} {"is_archived": true}
POST /articles/{id}/labels Assign label. Body: {"label_id": 1}
DELETE /articles/{id}/labels/{label_id} Remove label from article
Feeds
GET /feeds List subscribed feeds
POST /feeds Subscribe. Body: {"url": "...", "folder_id": null}
GET /feeds/{id} Get feed details
PATCH /feeds/{id} Update feed (title, folder, readable extraction, purge settings)
DELETE /feeds/{id} Unsubscribe from feed
Folders & Labels
GET /folders List folders
POST /folders Create folder. Body: {"name": "..."}
PATCH /folders/{id} Rename folder
DELETE /folders/{id} Delete folder (feeds moved to uncategorized)
GET /labels List labels
POST /labels Create label. Body: {"name": "...", "color": "#3b82f6"}
Auth
POST /auth/token Exchange email/password for a short-lived JWT (60 min). For long-lived access use an API token instead.
GET /auth/me Verify token and return current user info

All endpoints return JSON. Errors follow {"detail": "..."} format. 401 = invalid/revoked token.
